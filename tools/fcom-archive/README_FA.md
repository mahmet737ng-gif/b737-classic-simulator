# B737 Classic — FCOM offline extraction toolkit

**وضعیت: ابزار استخراج ساخته و روی PDF آزمایشی تست شده، اما دفترچهٔ کامل سپهران هنوز در این گفتگو استخراج نشده است.**

## هدف

ایجاد بانک اطلاعاتی مستقل از فایل PDF شامل:

- `pages/NNNNN.json`: متن هر صفحه، مختصات خطوط و کاراکترها/اسپن‌ها، متن اصلی، جدول‌های پیدا شده، ارجاع به تصاویر، شماره‌های احتمالی صفحات چاپی
- `text/NNNNN.txt`: متن قابل‌جست‌وجوی جداگانه برای هر صفحه
- `tables/`: فایل‌های CSV جدول‌های شناسایی‌شده + برش PNG از بخش جدول برای مقابلهٔ چشمی
- `figures/assets/`: تصاویر raster تعبیه‌شده، بدون تغییر بایت و با نام هش محتوا (تصویرهای تکراری مجدد ذخیره نمی‌شوند)
- `page-images/`: رندر PNG از *تمام صفحات* برای نگهداری جدول‌ها و دیاگرام‌های وکتوری که در PDF به‌صورت تصویر embedded نیستند. این بخش حائز اهمیت است چون استخراج صرفاً تصاویر embedded به معنی استخراج همهٔ شماتیک‌ها نیست.
- `fcom.sqlite`: جست‌وجوی صفحه‌به‌صفحه با FTS5؛ قابل استفاده برای موتور منطق سیستم‌های هواپیما
- `manifest.json`: SHA-256 فایل مبنا، تعداد صفحات، شمارش موارد استخراج‌شده، خطاها و وضعیت تکمیل واقعی

## اجرا روی ویندوز

1. Python 3.10 یا جدیدتر نصب باشد.
2. فایل PDF اصلی FCOM خودت را روی `run_windows.bat` بکش و رها کن؛ به اینترنت فقط برای نصب اولیهٔ PyMuPDF نیاز است.
3. استخراج را تا پایان و اجرای تأیید `verify_archive.py` صبر کن؛ ممکن است برای ~۱۹۳۷ صفحه و تصاویر حجیم ساعت‌ها طول بکشد و چند گیگابایت فضا نیاز باشد.
4. جست‌وجوی مثال:

```powershell
py search_archive.py "Autothrottle" --db "FCOM_EXTRACTED/fcom.sqlite"
```

## اجرا با فرمان

```powershell
pip install pymupdf
py extract_fcom.py "C:\Manuals\Sepehran-737CL-FCOM.pdf" --out "C:\B737\FCOM_EXTRACTED" --resume --render-dpi 120 --tables lines
py verify_archive.py "C:\B737\FCOM_EXTRACTED" --require-images
```

## کنترل کیفی و محدودیت‌ها

- `verify_archive.py` همهٔ صفحات را می‌شمرد، نه صحت معنی اعداد جدول‌ها. استخراج خودکار جدول‌ها دقیقاً معادل کنترل انسانی نیست؛ مرجع مطمئن همواره تصویر همان صفحه است.
- اگر PDF دارای صفحهٔ اسکن‌شده باشد، تصویری از آن ثبت می‌شود ولی متنِ خالی برای OCR نیازمند پردازش جداگانه است؛ هیچ متن حدسی تولید نمی‌شود.
- فایل‌های استخراج‌شده فرمت قابل‌استفاده برای AI، جست‌وجوی مستقیم، طراحی انجین و ارجاع به صفحه هستند؛ خود فایل PDF دیگر برای مرور و جست‌وجوی محتوای استخراج‌شده لازم نیست.
- **حق انتشار:** دفترچهٔ سپهران متعلق به Boeing و مشمول محدودیت قراردادی / کنترل صادرات اعلام‌شده در صفحهٔ نخست است. مخزن `mahmet737ng-gif/b737-classic-simulator` در حال حاضر PUBLIC است. محتوای کامل دفترچه را در آن قرار نده مگر مجوز صریح توزیع عمومی و رعایت محدودیت صادرات احراز شده باشد. مخزن خصوصی هم خودبه‌خود مجوز انتقال/دسترسی بین‌المللی ایجاد نمی‌کند.
- اجرای این ابزار کاملاً لوکال است؛ خود ابزار چیزی به شبکه یا GitHub ارسال نمی‌کند.

## اتصال به انجین

برای هر قانون از `fcom.sqlite` و `pages/NNNNN.json` شناسهٔ زیر را ثبت کنید:
`document_sha256 + pdf_page + printed_folio + exact bbox_pt + aircraft_variant + applicability`.
فقط رکوردهای نهایی‌شده را در دیتابیس عمومی کنترل‌ها منتشر کنید؛ تصاویر و صفحات کامل فقط در مخزن/فضای مجاز.

## مشاهدهٔ آفلاین صفحه‌ها و شکل‌ها در مرورگر

پس از استخراج، روی `view_windows.bat` دوبار کلیک کن. مرورگر، صفحه‌ها، جدول‌ها، تصاویر و جست‌وجوی FTS را نشان می‌دهد و فقط روی `127.0.0.1` (همان کامپیوتر) کار می‌کند. اینترنت یا PDF برای نمایش داده‌های استخراج‌شده لازم نیست.

```powershell
py browse_archive.py --archive "FCOM_EXTRACTED"
```

اگر استخراج ناقص باشد، مرورگر تعداد صفحه‌های موجود و کامل‌نبودن را نشان می‌دهد؛ فایل را برای کامل‌بودن جعلی علامت نمی‌زند.
