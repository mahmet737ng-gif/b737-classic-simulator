# TGL-0009 — approved CENTER

The new straight-down top-view CENTER pose was explicitly selected by the owner. The independent 768x768 transparent PNG is included here, as well as the 3840x768 lossless WebP atlas used by Unified, Fuel, and Flight Controls. Only atlas slot 1 (CENTER) was replaced; LEFT, RIGHT, UP, DOWN remain identical after pixel comparison with the previous atlas. Existing app positional semantics and state mapping stay untouched.
