# TGL-0003 — high-resolution cockpit toggle switch

Replaces the soft 112×112 imagery with five 768×768 transparent WebP cells on a 3840×768 atlas. The 5 positions are LEFT/CENTER/RIGHT/UP/DOWN. One immovable nut/disc/pivot is copied pixel-for-pixel in all five poses. Frozen OH source artwork and all previous V1/V2 assets are preserved. 2-state toggles use UP/DOWN, vertical three-position toggles use UP/CENTER/DOWN, horizontal three-position toggles use LEFT/CENTER/RIGHT. Control detents and system state remain unchanged.
