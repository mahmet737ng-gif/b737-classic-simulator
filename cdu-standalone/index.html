آزمایش اعلان‌ها

MSG از پیام Scratchpad و EXEC از تغییرات تأییدنشده به‌طور خودکار کنترل می‌شوند.

PRESENT N1 — Engine 1 / Engine 2

Default display uses SIM EST estimates when measured N1 is unavailable. Live engine telemetry overrides EST when provided. Manually injected values are marked TEST; none are AFM-validated or real flight data.

ENG1/ENG2 estimated N1 values appear when live data is absent.

Live source integration requires a separate Engine Core or simulator bridge. Readings expire automatically if updates stop; estimated values then return with the EST label.

EP-FSI — AFM N1 Source / Training

MAX N1 / TAKEOFF REF display an approximate SIM EST value for training (TO/GA generally 88–95%). These are NOT approved AFM performance values. Manual N1 input remains MAN.

ISA / Bleed ON / Anti-ice OFF

Page N1 LIMIT shows EST values even without verified AFM tables; true AFM calculation remains unverified. No autothrottle commands are issued.

راهنمای اجرا

روی RTE کلیک کن، فرودگاه چهارحرفی را با صفحه‌کلید CDU وارد کن و LSK L1 را بزن. سپس مقصد را در LSK R1 ثبت کن. چراغ EXEC روشن می‌شود؛ کلید EXEC را فشار بده.

فشردن CLR یک حرف را پاک می‌کند و نگه‌داشتن آن Scratchpad را خالی می‌کند. DIM BRT روشنایی تصویر را در حالت تمرینی تغییر می‌دهد.

این نمونه شبیه‌ساز رفتار ورودی و صفحه‌ها است؛ هنوز ناوبری، محاسبات Performance یا مسیر واقعی هواپیما را انجام نمی‌دهد.
