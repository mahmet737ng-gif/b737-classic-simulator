# ماژول تعاملی پنل سوخت B737 Classic — نسخه ۱

این بسته یک بازسازی روبه‌روی پنل سوخت با کنترل‌های مستقل و قابل اتصال به انجین شبیه‌ساز است.

## رفتار اجراشده

- شش کلید Fuel Pump مستقل هستند و فقط فرم واقعی همان کلیدها لمس/انتخاب می‌شود؛ هیچ حلقه یا کادر انتخابی دیده نمی‌شود.
- تاگل‌ها از جفت تصویر واقعی OFF/ON استاندارد `b737-cockpit-toggle-v1` استفاده می‌کنند؛ زاویهٔ دید، ساقه، سایه و Foreshortening در دو حالت واقعاً متفاوت است.
- عقربهٔ FUEL TEMP از تصویر ثابت جدا شده و با Drag/Touch، کلیدهای جهت‌دار یا API حرکت می‌کند.
- با قرار دادن Pump روی ON، چراغ LOW PRESSURE ابتدا روشن می‌ماند و بعد از تشکیل فشار خاموش می‌شود.
- با OFF شدن Pump، فشار LOW و چراغ مربوط روشن می‌شود.
- ناب CROSSFEED از CLOSED به OPEN می‌چرخد. هنگام حرکت شیر، VALVE OPEN به‌صورت BRIGHT و پس از بازشدن کامل به‌صورت DIM نمایش داده می‌شود. در حالت بسته چراغ خاموش است.
- چراغ‌های FUEL VALVE CLOSED سه وضعیت OFF / DIM / BRIGHT دارند و در دموی فعلی با لمس مستقیم چراغ برای تست چرخه می‌شوند.
- چراغ‌های FILTER BYPASS برای Fault Injection با لمس مستقیم روشن/خاموش می‌شوند.
- کلید HOLD LAMP TEST تا زمان نگه‌داشتن، همه چراغ‌ها را در حالت BRIGHT قرار می‌دهد.
- نور همهٔ Annunciatorها داخل لنز فیزیکی Clip شده و از قاب مشکی بیرون نمی‌زند.
- موقعیت هر ۱۱ لنز به‌صورت مستقل با قاب واقعی تصویر کالیبره شده است؛ اندازهٔ عمومی یا Offset مشترک برای چراغ‌ها استفاده نمی‌شود.

## اتصال به انجین

هر تغییر یک رویداد `b737:fuel-panel-change` روی `window` منتشر می‌کند. وضعیت جاری در `window.B737FuelPanelState` در دسترس است.

API تست:

```js
B737FuelPanel.getState();
B737FuelPanel.setPumpPressure('tank1Fwd', true);
B737FuelPanel.setPumpFailure('ctrL', true);
B737FuelPanel.setAvailableFuel('ctrR', false);
B737FuelPanel.setFuelTemperature(-12);
```

فایل `animation-spec-registry.json` نام کنترل‌ها، زمان حرکت، وضعیت‌ها و قرارداد اتصال را ثبت کرده است تا همین منطق در پنل‌های بعدی دوباره استفاده شود.

## اجرا

فایل `index.html` را باز کنید. بسته بدون کتابخانه یا اتصال اینترنت اجرا می‌شود و برای ماوس، لمس و کیبورد آماده است.
