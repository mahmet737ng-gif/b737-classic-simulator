# Engine Start Detent Lab — B737 Classic

نمونهٔ مستقل دو سوییچ Engine Start با چهار وضعیت `GRD → OFF → CONT → FLT`.

- هر حرکت موس/لمس به اندازهٔ آستانه، یک دیتند در جهت حرکت جابه‌جا می‌کند؛ ناب با انگشت آزادانه نمی‌چرخد.
- هنگام رهاکردن انگشت، حالت جدیدی انتخاب نمی‌شود.
- چهار زاویه برای هر موتور مستقل و از مختصات مرکز نوشته‌ها نسبت به مرکز سوییچ محاسبه شده‌اند؛ زاویه‌ها لزوماً مساوی نیستند.
- در نمایش آزمایشی، نوشتهٔ FLT برای هر دو موتور از CONT دورتر قرار گرفته است. این اصلاح روی نسخهٔ نمایشی به‌صورت لایهٔ برداری/تکسچر مجزا است و فایل خام و موزاییک قفل‌شده هیچ تغییری نکرده‌اند.
- موتور ۱ و ۲ مستقل‌اند. تغییر وضعیت یک سوییچ، روی دیگری اثر نمی‌گذارد.
- رویداد `b737-engine-start-detent-change` و API `B737_ENGINE_START_TEST` برای اتصال بعدی به Unified در دسترس‌اند؛ این دمو به سیستم اصلی سیمولاتور فرمان نمی‌دهد.

پیش‌نمایش: `engine/engine-start-detent-lab/index.html`؛ تست: `node engine/engine-start-detent-lab/tests/engine-start.test.cjs`.

**محدودیت:** زاویهٔ ظاهری از نشانه‌های همین پنل محاسبه شده و مستقل از منطق الکتریکی/مکانیکی راه‌اندازی موتور است. برگشت خودکار GRD به OFF فقط باید توسط منطق مستند سیستم موتور صادر شود؛ در اینجا حدس زده نشده است.
