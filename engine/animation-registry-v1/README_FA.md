# B737 Classic — Animation Spec Registry v1.0

**وضعیت:** هستهٔ اجرایی + رجیستری نسخه‌دار + دموی تست و ادغام EFIS. **این نسخه هنوز Animation Engine عملیاتی کل هواپیما نیست.**

## داده‌های مرجع

- **EFIS FSI:** چهارده کنترل تصویر FCOM، فصل ۱۰، صفحات چاپی 10.30.2–10.30.5، PDF 1322–1325. برای این کنترل‌ها مختصات روی برش اصلی FCOM ثبت شده است.
- **MCP FSI:** ۲۳ کنترل منتخبِ قابل تعامل طبق Chapter 4، بخش 4.10.1–4.10.20، PDF 1044–1063. نام، نوع، حالت‌ها و بعضی مقادیر محدودیت منبع دارند؛ مختصات پیکسلی MCP هنوز به شکل اصلی کالیبره نشده است.
- پیکربندی A/P ENGAGE Paddle برای **FSI** استفاده شده؛ bar مربوط به پیکربندی دیگر به این مجموعه اضافه نشده است.
- هیچ تصویر FCOM در پوشهٔ عمومی GitHub قرار نمی‌گیرد. آزمایش EFIS با تصویر FCOM در ZIP خصوصی قابل اجراست.

## فایل‌ها

- `data/animation-registry.json`: تنها فهرست تعاریف کنترل‌ها (۳۷ کنترل).
- `data/animation-registry.js`: همان داده، برای اجرای مستقیم فایل HTML بدون fetch.
- `data/control-register.csv`: نمای مهندسی برای QA و ارجاع به FCOM.
- `motion-engine.js`: موتور مشترک state / interlock-agnostic visual motion.
- `pointer-interactions.js`: event adapter موس/لمس/قلم/کیبورد.
- `demo/`: دموی *آزمایشگاهی* با کارت‌های خنثی؛ **نه طرح پنل هواپیما**، بدون کپی artwork.
- `private-efis/`: نسخهٔ آفلاینِ کامل با اصل تصویر FCOM و حرکت نرم تصویر ناب‌ها؛ برای انتقال به public GitHub نیست.
- `tests/`: تست‌های Node.js.

## تفکیک «طبق FCOM» از «نمایش UI»

مشخصات تأییدشده از FCOM: نوع کنترل، حالت‌های قابل انتخاب، برخی محدوده‌های عددی، نقش کنترلی و ارجاعات. **زاویهٔ دقیق مکانیکی، مدت حرکت و easing از FCOM استخراج نشده‌اند.** مقادیر `preview_step_degrees`, `duration_ms` فقط تنظیم آزمایشی UI هستند، تا بعد از بررسی مرجع هندسی/ویدئویی قابل تغییر باشند. هیچ‌کدام به سیستم واقعی هواپیما command نمی‌دهند.

## قواعد انیمیشن

- موتور وقتی فرمان جدید می‌رسد مقصد بصری را تغییر می‌دهد؛ CSS transition از وضعیت بصری جاری تا مقصد تازه interpolate می‌کند. اگر چند پله پشت سر هم دریافت شود «جهش آنی» اتفاق نمی‌افتد.
- دو ناب هم‌محور `EHSI_BRT_OUTER` و `WXR_BRT_INNER`، همین‌طور `EHSI_RANGE` و `TFC`، وضعیت مستقل دارند. `MCP.HEADING_SELECTOR` و `MCP.BANK_ANGLE_SELECTOR` هم مستقل هستند.
- لحظه‌ای‌ها با press تغییر شکل می‌دهند و با release، cancel و blur به حالت اول برمی‌گردند.
- `prefers-reduced-motion` برای حذف انیمیشن در مرورگر پشتیبانی شده است.
- رابط pointer از تپ/کلیک، اسکرول، سوایپ و کلیدهای جهت‌دار پشتیبانی می‌کند. «کلیک شبح» بعد از سوایپ حذف می‌شود.

## محدودیت‌ها

این رجیستری نه جای FCOM را می‌گیرد و نه logic سیستم‌های AFDS، A/T، LNAV، VNAV و warning را جایگزین می‌کند. هندسهٔ کنترل MCP، دقیق‌شدن زاویه‌های حقیقی و بررسی عملی iPad در فاز بعدی است. تصویر EFIS داخلی یک گرافیک منبع از FCOM است و بخش‌های ناوبری تصویر همچنان نمونهٔ چاپی، نه دادهٔ live، هستند.
