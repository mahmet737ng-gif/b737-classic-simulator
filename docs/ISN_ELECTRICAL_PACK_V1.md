## Two explicitly separated execution modes

| Mode | Equipment ↔ Bus behavior | Default? |
|---|---|---|
| `SOURCE_GATED` | Equipment feed UNKNOWN except proven V8 absence of its known voltage class, or an independently labeled instructor-observed power sensor. No guessed Bus assignment. | Yes |
| `TRAINING_SURROGATE` | Uses **only** `engine/trainer/core.js`'s existing synthetic transfer-bus mapping, each result labeled `TRAINING_SURROGATE_UNVERIFIED_BUS_ASSIGNMENT`. Requires explicit instructor selection. | No |

The source-gated mode is the path toward validated source-by-source integration. The surrogate mode tests dependency propagation and UI without converting guesses into verified EP-FSI/737CL wiring.
